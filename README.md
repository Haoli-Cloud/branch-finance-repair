# 我做账时总结的八个步骤

从整理银行流水到核对报表，一套可交给 AI 助手执行的中文做账流程。

- [做账步骤](SKILL.md) · 定范围、理流水、分收入、分支出、核扣款和返还、算收益、做对账、出报表。
- [核对与交付](references/system.md) · 遇到分配差额、重复记录、跨月或资料缺失时怎样处理。

## 使用

点 **Code → Download ZIP** 并解压。保留 `SKILL.md` 和 `references/` 的相对位置。可以将文件夹命名为 `branch-finance-repair` 并放入项目的 `.agents/skills/`，也可以让 AI 助手直接读取 `SKILL.md`。

## 修改

点 **Fork** 创建自己的副本，按自己的账务口径修改。如想把改动分享回本仓库，可提交 Pull Request。使用和再分发须保留 [MIT 许可证](LICENSE)及版权声明。
